# Sound credits

Recordings used by the soundscape (`src/audio/soundscape.ts`, listed in `SFX_FILES` in
`src/audio/soundscapeConfig.ts`). Only CC0, CC BY and public-domain files are allowed here. CC BY
files need the attribution below to stay with the project.

All files were converted to mono, 44.1 kHz MP3 (96 kbit/s) with ffmpeg. Other changes are listed per file.

## Pedestrian chatter (`pedestrians/`)

None yet. No licence-safe recording of people chatting in English outdoors was found on Wikimedia
Commons or OpenGameArt, so conversations still use the procedural murmur. To add clips: put them in
`pedestrians/`, list them under `chatter` in `SFX_FILES`, and add a row here.
